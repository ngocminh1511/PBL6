## Vị trí và sử dụng

Manifest tại `data/raw/appendix/manifest.json` và `data/processed/appendices_v1/artifacts.json` đã có `storage_backend=r2` và metadata bucket/key/hash/verified_at. Tất cả file local vẫn còn, đã kiểm tra hash. Bản manifest trước khi chuyển lưu tại `data/raw/appendix/manifest.before_r2.json`.

API vẫn dùng `/api/files/{artifact_id}`. Với file đã xác minh, backend trả URL ký tạm thời để tải từ R2, không bật truy cập công khai cho bucket. Khi R2 tạm lỗi, dùng bản local nếu còn có sẵn. Không lưu Access Key/Secret Key hoặc URL ký tạm thời vào báo cáo.

Kiểm tra API với file thật của TT 09/2020:

| Kiểm tra | Kết quả |
|---|---|
| PDF xem trực tiếp | API 307 → R2 200, hash khớp |
| PDF yêu cầu byte range | HTTP 206, nội dung khớp |
| PDF tải xuống theo yêu cầu | Content-Disposition attachment |
| Word tải xuống | API 307 → R2 200, hash khớp |
| HTML nguồn tải xuống | API 307 → R2 200, hash khớp |
| ID/chunk/graph/ABox | Hash các file dữ liệu giữ nguyên |
| Bản local | 116/116 file nguồn còn nguyên hash |
